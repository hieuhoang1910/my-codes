# Engineering and Software Development Portfolio

This repository contains a curated collection of engineering and software projects spanning embedded systems, C/C++ development, aerospace engineering, thermal analysis, and experimental data processing. Each folder represents a self-contained project with source code and supporting documentation.

---

## Project Index

### Endoscopy Camera System (C++ OOP + HAL Architecture)
A simulated multi-camera medical imaging pipeline demonstrating object-oriented design, inheritance, virtual interfaces, and a Hardware Abstraction Layer (HAL) approach similar to real medical device software.

Key features include:
- Independent camera device classes (White-Light, Infrared, Diagnostic)
- Threaded capture loop using a centralized `CameraManager`
- Modular class structure with clear device abstraction layers
- Cross-platform design with simulated Linux/Windows device hooks
- Example of embedded-style C++ programming relevant to medical imaging and device software

---

### FEA-Beam-Problem
Finite Element Analysis (FEA) implementation for 1D axial deformation. Includes stiffness matrix assembly, boundary condition application, nodal displacement calculation, and reaction force evaluation.

---

### Shock-Tube-Analysis
Processes pressure transducer voltage data from a shock tube experiment. Includes:
- Voltage-to-pressure conversion
- Shock strength and Mach number computation
- Wave propagation visualization
- Filtering and alignment of multi-sensor measurements

---

### Turbojet-Engine-Performance
Analyzes SR-30 turbojet engine data to estimate:
- Compressor and turbine efficiencies
- Thermal cycle parameters
- Power and thrust contributions
The analysis uses ideal gas relations and standard thermodynamic equations.

---

### Uncertainty-RSM-Analysis
Monte Carlo simulation and Response Surface Methodology (RSM) for probabilistic engineering design. Demonstrates uncertainty propagation, sensitivity analysis, and design-space modeling.

---

### Vehicle-Efficiency-Model
Computes vehicle power demand as a function of aerodynamic drag, rolling resistance, and drivetrain efficiency. Useful for EV and hybrid powertrain studies.

---

### Voltage-Conversion-Script
Automates the conversion of pressure transducer voltage readings to psi using calibrated sensitivity values. Supports efficient and consistent experimental data processing.
